# TrackFlow Website

Aplicacion web corporativa de TrackFlow en Next.js + TypeScript.

## Objetivo
Presentar propuesta de valor, secciones completas del Hito 1 y formulario de aplicacion comercial B2B.

## Rutas
- / : landing corporativa
- /apply : formulario de aplicacion

## Scripts
- npm run dev
- npm run build
- npm run lint
