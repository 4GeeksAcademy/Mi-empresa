# .agents

Directorio de configuracion de agentes de desarrollo.

- rules/: reglas operativas que el agente debe aplicar al editar codigo.
- skills/: habilidades reutilizables para tareas recurrentes del flujo de trabajo.

No confundir con:
- agents/: activos de producto para agentes de negocio.
- skills/: activos de producto para flujos funcionales.
